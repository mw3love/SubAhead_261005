## 자세한 설명

자막이 없는 웹 영상에 한국어 자막을 만들어 주는 확장 프로그램입니다.

버튼 한 번이면 영상 전체의 소리를 미리 받아 적어, 시간표가 붙은 자막을 만듭니다. 그래서 영상을 앞뒤로 아무리 넘겨도 그 장면의 자막이 바로 나타납니다. 한 번 만든 자막은 브라우저에 저장되어 다시 볼 때는 바로 불러옵니다.

주요 기능
- 페이지 안의 HTML5 영상(일반 영상 파일, HLS 스트림)을 자동으로 찾습니다.
- 한 페이지에 영상이 여러 개면 체크 목록(페이지 순서)에서 빼고 싶은 영상만 끄고 나머지를 한 번에 만들 수 있습니다. 앞 영상이 받아 적히는 동안 다음 영상을 미리 준비해 기다리는 시간을 줄입니다. 영상 위 오른쪽 클릭 메뉴로 그 영상 하나만 만들 수도 있습니다.
- 영상에서 소리만 뽑아 음성인식 서버로 보냅니다. 화면 데이터는 보내지 않습니다.
- 브라우저 기본 자막 기능으로 표시하므로 전체화면에서도 자막이 보입니다.
- 만들기 전에 영상 길이와 예상 비용, 남은 크레딧을 보여 줍니다.
- 진행 상황을 단계별로 보여 주고, 아이콘 배지와 영상 위 알림으로도 알려 줍니다. 진행 중에 취소할 수 있습니다.
- 팝업의 "모양" 탭에서 미리보기를 보며 글자 크기·색과 배경을 바꿀 수 있습니다.
- 팝업의 크기 막대, 또는 영상 위에서 Alt(Mac 은 Option)+휠로 자막 크기를 10~250% 사이에서 바로 바꿀 수 있습니다.
- 영상 위에서 Alt(Mac 은 Option)+드래그로 자막을 위아래·좌우로 옮길 수 있습니다.
- 단축키로 자막 켜기·끄기, 크기 바꾸기, 싱크를 0.5초씩 맞출 수 있습니다.
- 한 번 만든 자막은 저장되어, 같은 영상을 다시 열면 자동으로 붙습니다. 맞춘 싱크도 영상별로 기억합니다.
- 만든 자막을 SRT(플레이어용)·TXT(읽기용, 문장별 또는 시간 표시)로 받거나 복사할 수 있습니다. 보관함 탭에서 지금까지 만든 자막과 사용 공간을 보고, 제목을 눌러 그 페이지를 열거나 지울 수 있습니다.

사용 방법
1. 확장 아이콘을 누르고, 음성인식 모델 stt-async-v5 를 제공하는 본인의 API 게이트웨이 주소(Base URL)와 키를 넣습니다.
2. 영상이 있는 페이지에서 확장 아이콘을 누르고 "전체 자막 만들기"를 누릅니다.
3. 자막이 완성되면 영상을 자유롭게 넘겨 보세요.

기본 단축키 (chrome://extensions/shortcuts 에서 바꿀 수 있음)
- 자막 만들기: 기본 키 없음(직접 지정). 한 번 누르면 비용을 알려 주고, 4초 안에 한 번 더 누르면 시작합니다.
- Alt+Shift+S: 자막 켜기·끄기
- Alt+Shift+↑: 자막 크기 바꾸기
- Alt+Shift+← / →: 자막 0.5초 빠르게 / 늦게
(Mac 에서는 Alt 대신 Option)

알아 두세요
- 음성인식 비용은 사용자 본인의 게이트웨이 요금으로 청구됩니다. 게이트웨이가 크레딧 정보를 제공하면 만들기 전에 남은 크레딧과 예상 비용을 보여 줍니다.
- 암호화(DRM)된 영상은 지원하지 않습니다.
- 시청 권한이 있는 영상에만 사용해 주세요. 이 확장은 영상을 저장하거나 내려받는 기능을 제공하지 않습니다.

## 단일 목적 설명

웹페이지의 영상 소리를 받아 적어, 그 영상에 시간이 맞는 자막을 표시한다.

## 권한별 사용 이유

- `webRequest`: 페이지가 불러오는 영상 스트림 주소(m3u8, mp4)를 찾기 위해 요청 주소만 읽습니다. 요청을 막거나 바꾸지 않습니다.
- `scripting`: 사용자가 버튼을 누른 탭에서 영상 요소의 주소와 크기를 읽기 위해 사용합니다.
- `storage`: 사용자의 API 키, 만든 자막(영상 제목·주소 포함), 자막 모양 설정, 영상별 싱크 값을 이 브라우저에만 저장하기 위해 사용합니다.
- `offscreen`: 영상에서 소리만 뽑는 작업(확장에 포함된 ffmpeg.wasm)을 보이지 않는 문서에서 실행하기 위해 사용합니다.
- `activeTab`: 사용자가 버튼을 누른 현재 탭에 자막을 붙이기 위해 사용합니다.
- `contextMenus`: 영상을 오른쪽 클릭했을 때 "이 영상 자막 만들기" 메뉴를 보여 주기 위해 사용합니다. 영상 요소에서만 나타납니다.
- `declarativeNetRequestWithHostAccess`: 확장이 영상 데이터를 받을 때, 영상이 재생되던 페이지 주소를 Referer/Origin 으로 붙이기 위해 사용합니다. 일부 영상 서버는 이 정보가 없으면 요청을 거절합니다. 확장 자신이 보내는 영상 요청에만 적용되며, 음성인식 게이트웨이 요청이나 다른 웹사이트의 요청은 바꾸지 않습니다.
- 호스트 권한 `<all_urls>`: 영상은 어느 사이트에나 있을 수 있고, 영상 데이터를 받으려면 그 주소에 대한 권한이 필요합니다. 음성인식 게이트웨이 주소 접근에도 사용합니다.

- Name: SubAhead – Full-video Korean subtitles
- Summary (manifest description):
  Transcribes a video's audio ahead of time so Korean subtitles stay in sync wherever you seek. Requires your own API gateway address and key.

### Description

SubAhead creates Korean subtitles for web videos that don't have any.

With one click it transcribes the whole video's audio in advance and builds time-coded subtitles, so the right line appears wherever you seek. Subtitles are saved in your browser and applied automatically the next time you open the same video.

Features
- Finds HTML5 videos on the page automatically (regular video files and HLS streams).
- Sends only the audio to the speech recognition server — never the picture.
- Uses the browser's built-in subtitle display, so subtitles also work in full screen.
- Shows the video length, estimated cost and your remaining credits before you start.
- Shows progress step by step, plus an icon badge and an on-page notice.
- On pages with several videos, uncheck the ones you don't want in a checklist (in page order) and the rest are made in one go, preparing the next video while the previous one is being transcribed. Or right-click a video to make subtitles for just that one.
- Cancel while subtitles are being created.
- Customize the subtitle style with a live preview in the Style tab: text size and color, background.
- Resize subtitles between 10% and 250% with the size slider in the popup, or with Alt (Option on Mac) + mouse wheel over the video.
- Move subtitles up, down, left or right by Alt (Option on Mac) + dragging over the video.
- Keyboard shortcuts to toggle subtitles, change the size, and shift timing by 0.5 seconds.
- Remembers your timing adjustment for each video. Download subtitles as SRT (for players) or TXT (one sentence per line, optional timestamps), or copy them. The Library tab lists everything you've made: open the page, download or delete.

How to use
1. Click the extension icon and enter the address (Base URL) and key of your own API gateway that provides the stt-async-v5 speech recognition model.
2. On a page with a video, click the icon and press "Create full subtitles".
3. When it's done, seek anywhere in the video.

Default shortcuts (change them at chrome://extensions/shortcuts)
- Create subtitles: no default key (set your own). Press once to see the cost, press again within 4 seconds to start.
- Alt+Shift+S: toggle subtitles
- Alt+Shift+Up: change subtitle size
- Alt+Shift+Left / Right: subtitles 0.5s earlier / later
(Option instead of Alt on Mac)

Good to know
- Speech recognition is billed by your own gateway. If the gateway reports credits, the remaining credits and an estimated cost are shown before you start.
- Transcription is Korean only. Encrypted (DRM) videos and live streams are not supported.
- Please use it only on videos you're allowed to watch. This extension does not save or download videos for you.
